## Hard rules

- `dev.stagecraft.jenkins` has **no IntelliJ imports** (§9.1). Proxy/TLS arrive as injected `ProxySelector`/`SSLContext`; `JenkinsHttp` never reads IDE settings.
- **JVM target trap:** emit Java 17 bytecode (`jvmTarget = 17`) while `since-build < 242` (§9.1).
- Cookies: one cookie store per server inside `JenkinsHttp`, reused; never a new client per request (§9.2).
- Crumb: fetched/cached only for password auth; API-token POSTs are crumb-exempt. A wrong crumb is ignored by the server — never fail because crumb fetch failed.
- Timeouts: connect 5 s, read 20 s (§9.2).
- Token validation is `GET /me/api/json` **and** comparing returned `id` to the configured user (a 200 with `anonymous` is not a good token).
- Fixtures: `docs/fixtures/**` is `-text` in `.gitattributes` — byte-exact, never re-normalise line endings.
