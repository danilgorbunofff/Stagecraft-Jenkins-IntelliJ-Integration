## Part A — ConsoleStages.kt (the parser)

**Executable spec:** `tools/parse_stages.py` (223 lines) + `tools/test_parse_stages.py` (16 test
methods). Port **one-for-one**. A stack-based parser over `[Pipeline]` markers.

### Regexes (after stripping ANSI `\x1b\[[0-9;]*m` and `\r`)

```
MARKER         ^\[Pipeline\] (sets isPipelineLog)
NAMED_OPEN     ^\[Pipeline\] \{\s*\((.*)\)\s*$   stage body, or "Branch: x" in parallel
BLOCK_OPEN     ^\[Pipeline\] \{$                 anonymous block (node, withEnv, script…)
BLOCK_CLOSE    ^\[Pipeline\] \}$                 pops innermost; popping a STAGE frame fixes its last line
STAGE_CLOSE    ^\[Pipeline\] // stage$           informational — must NOT pop
PARALLEL_OPEN  ^\[Pipeline\] parallel$
PARALLEL_CLOSE ^\[Pipeline\] // parallel$
SKIPPED        ^Stage "(.+)" skipped due to (.+)$
END            ^\[Pipeline\] End of Pipeline$
FINISHED       ^Finished: ([A-Z_]+)$
ERROR_LINE     ^(?:ERROR: |FATAL: |\[ERROR\] |FAILURE: |BUILD FAILED\b|Exception in thread )|^Build step '.+' marked build as failure$
```

### Core semantics (port exactly)

- Stack of open frames; `NAMED_OPEN`/`BLOCK_OPEN` push, `BLOCK_CLOSE` pops (a stage frame popped fixes `last` — only when **not** inside an open parallel region).
- `Branch: ` prefix in `NAMED_OPEN` → branch frame (not a stage); records `region.branches`.
- `STAGE_CLOSE`: informational. If the last popped thing was not a stage and no regions are open → count a `stray_stage_close`.
- `PARALLEL_OPEN` opens a region `{first, base = len(stack), stages[], branches[], claimed}`; `PARALLEL_CLOSE` pops it, deletes `stack[region.base:]`, gives each region stage `first/last = region range`, records the closed region.
- After the loop: stages with `last == null` get `last = lineCount, open = true`. Sort by `first` (stable).
- Synthetic flag: names starting `Declarative: ` (incl. `Declarative: Post Actions`).

### The four rules the first version got wrong (§9.3) — all test-covered

1. `// stage` closes nothing.
2. A stack cannot match `parallel`. No per-branch prefix (JEP-210). Stages inside a parallel region carry **the whole region's range** and `interleaved: true`.
3. `Declarative: …` stages are synthetic; never chosen as "the failed stage" unless the first error is inside them (`Post Actions` never).
4. The console has no stage status. `SKIPPED` marks skips; the failed stage is **inferred** (innermost non-interleaved stage containing the first error, else last executed non-synthetic non-skipped stage) and returned **with its basis** (`first-error-inside-stage` / `last-executed-stage`, plus `, parallel-ambiguous` when interleaved).

### Parallel placement (`_place_stage`), port verbatim

- Owner = nearest stage in `stack[:region.base]`.
- `unclaimed` = declared lanes not yet claimed. If name ∈ unclaimed → `branch = name`, `laneBinding = "name"`.
- Elif unclaimed and **all** open lanes already have a branch → k-th unclaimed lane = k-th branch, `laneBinding = "positional"`, `parentUncertain = true`, mark claimed.
- Elif exactly one open lane has a branch → parent = that lane, branch = its label.
- Else parent = owner, `parentUncertain = bool(open_lanes or region.branches)`.

### Diagnostics to return

`stackLeftAtEnd, endMarkerSeen, isPipelineLog, fallbackMode ('stages' | 'pipeline-without-stages' | 'plain-log'), result, firstErrorLine, firstErrorStage, inferredFailedStage (+basis), parallelRegions (closed), unattributedStages (parentUncertain names), strayStageClose`.

1. `{build}/wfapi/describe` → stages with real `status`, `startTimeMillis`, `durationMillis`, `error.message` — **richer, use when present**. Fixture `docs/fixtures/12.wfapi.json`. For per-stage log text prefer `{build}/execution/node/{id}/wfapi/log` (R2: returns `{"length":0,"hasMore":false}` on 2.541.3 — verify before relying).

## Part B — RemoteMatcher.kt + JobIndex.kt (§9.4, six steps)

1. **Cheap tree fetch.** `tree=jobs[name,_class,jobs[name,_class,jobs[name,_class]]]` in **one** request; recurse into any item returning a `jobs` array (Folder, OrganizationFolder, multibranch — not one `_class`). **Never request `url`** (reverse-proxy trap, R4) — build paths yourself with double URL-encoding (`feature%2FORD-214` → `feature%252FORD-214`). Bound by containers, not jobs.
2. **Rank candidates by name** (repo derived from remote): 100 multibranch name == repo; 80 any decoded name == repo; 60 name contains repo; 50 name contains a distinctive remote segment. Tie-break: depth, then name.
3. **Confirm with ONE build** — `{branchJob}/{n}/api/json?tree=actions[remoteUrls,lastBuiltRevision[SHA1,branch[name]]]` (fixture `07.remotedata.json`). Three traps: (a) PR-N fallback — branches filed as PRs have no branch job; look at `PR-*` children and their source branch (`r8-*` fixtures; `PrSourceResolver` is a pluggable interface, `null` = unresolved, honestly); (b) `remoteUrls` is a list, several BuildData actions — match after normalisation (lower-case host, strip `.git` and trailing `/`, `git@host:o/r` ≡ `ssh://…` ≡ `https://…`); (c) 404 may mean **no permission** → "not found, or not visible to this account".
4. **Cache is the product.** `{systemPath}/stagecraft/index-{sha1(serverUrl)}.json`; on IDE start populate instantly, refresh in background. Cap 2,000 jobs (configurable) with the honest message *"indexed 2,000 of N jobs; pin your job manually for an exact match"*; flags `truncated` + `totalSeen`. kotlinx-serialization via manual `JsonObject` building (no `@Serializable` in this codebase).
5. **Manual pinning always wins** (`Select job…` picker with query box, stored in project settings, never overridden).
6. **Never block.** Background task, `ProgressIndicator`, honour cancellation; empty state renders immediately (7.3 rule 2).
