## Part B — The acceptance test (§7.6)

A stranger, given IntelliJ, a git clone of a multibranch repository, a Jenkins URL + API token, on a **1,000-job server with CSRF on, over HTTPS, behind a proxy**, must:

1. open the project and see the tool window populate **without typing the job name**;
2. see their own branch's builds within **10 seconds**;
3. open the newest failed build, failed stage's log on screen, scrolled to the first error, within **3 seconds**;
4. Ctrl-click a stack frame and land on the right line of the right file;
5. see the build's test results;
6. lose network and see a **retry prompt, not a freeze**;
7. restart the IDE and find the configuration intact.

*If all seven hold, the product is done. That is the whole bar.*
